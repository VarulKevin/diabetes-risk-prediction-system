# Diabetes Risk Prediction & Predictive Analytics System

## Overview

This project is an end-to-end machine learning system developed to predict diabetes risk using healthcare datasets. The project demonstrates the complete data science workflow including:

- Data cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training & evaluation
- Predictive analytics
- Interactive visualization

The system was developed as an academic analytics project focused on applying machine learning techniques to healthcare risk prediction and decision-support analytics.

---

# Objectives

- Predict diabetes risk using healthcare indicators
- Identify key features influencing prediction outcomes
- Compare machine learning model performance

- Demonstrate practical machine learning workflow implementation
